# GGprofile

## 1. 概要

ゲーマー向けの自己紹介カード作成・共有サービス。プレイしているゲームのランク、メインキャラクター、プレイスタイルなどをカード形式でまとめ、SNSで簡単にシェアできるWebアプリケーション。

## 2. 背景・課題

### 現状の課題
- ゲーマーが自分のプロフィールをSNSでシェアする際、スクリーンショットを撮ったり自分で画像を作成する必要がある
- 統一されたデザインで見やすいカードを作成するには、画像編集スキルやツールが必要
- カード画像だけでは詳細情報を伝えきれず、リンク先で詳しく見てもらう手段がない

### 解決アプローチ
- 統一されたデザインテンプレートで、誰でも簡単に見やすいプロフィールカードを作成
- シェア用URLと詳細プロフィールページにより、興味を持った人に追加情報を提供
- OGP対応でSNSシェア時にカードがプレビュー表示される

## 3. ターゲットユーザー

### プライマリユーザー
- 自分のランクやメインキャラをSNSでアピールしたいゲーマー
- 一緒に遊ぶフレンドを募集したい人

### セカンダリユーザー
- 配信者やクリエイターで、視覚的にプロフィールを見せたい人
- チームやクランのメンバー募集をしたい人

### ユーザーの特徴
- X（Twitter）やDiscordを日常的に利用
- スマートフォンでの利用がメイン
- 10代後半〜30代が中心

## 4. 機能一覧

### MVP（必須）

#### プロフィールカード作成
- [ ] ゲーム内ネーム入力
- [ ] ランク選択（ゲームごとのランクシステムに対応）
- [ ] メインキャラクター/エージェント選択
- [ ] プレイスタイル選択（カジュアル/ランク/大会志向など）
- [ ] ひとこと自己紹介入力
- [ ] SNS ID入力（X、Discord等）

#### 画像・デザイン
- [ ] プロフィール画像設定（アップロードまたはプリセット選択）
- [ ] 背景デザイン選択（プリセットから選択）
- [ ] カードテーマ選択（ライト/ダーク等）

#### 共有機能
- [ ] カードをPNG画像としてダウンロード
- [ ] 固有のシェアURL発行（`/cards/{id}` 形式）
- [ ] URLコピーボタン（ワンクリックでクリップボードにコピー）
- [ ] 動的OGP生成（カードごとにog:imageを動的に設定）
- [ ] Xシェアボタン（Web Intent：URL付きテキストを事前入力）

**Xシェアの仕組み（API不要）:**
1. ユーザーがXシェアボタンを押す
2. Web Intentで X の投稿画面に遷移
3. テキスト＋シェアURLが事前入力された状態
4. XがURLを解析し、OGP画像（＝作成したカード）をプレビュー表示
5. ユーザーがツイートボタンを押して投稿完了

**その他SNS（Instagram等）向け:**
- 画像ダウンロード＋URLコピーで対応

#### プロフィールページ
- [ ] シェアURL先の詳細プロフィールページ
- [ ] カード情報の詳細表示
- [ ] SNSリンク一覧

## 5. 非機能要件

### 対応環境
- **ブラウザ**: Chrome, Safari, Edge, Firefox 最新版
- **デバイス**: スマートフォン（iOS/Android）、タブレット、PC
- **レスポンシブ**: モバイルファースト設計

### パフォーマンス
- カード生成: 3秒以内
- ページ読み込み: 2秒以内（LCP）

### セキュリティ
- アップロード画像のサイズ・形式制限
- 不適切コンテンツのフィルタリング（将来）

### 可用性
- 24時間365日稼働（Vercel）
- 月間稼働率99%以上

## 6. マネタイズ

### 広告収入
- カード作成フロー中にインタースティシャル広告（課金ユーザーは非表示）
- サイト内にGoogle AdSense等のバナー広告

### フリーミアムモデル

| 項目 | 無料プラン | 有料プラン |
|------|-----------|-----------|
| カード保存枠 | 3枚まで | 無制限 |
| 広告 | 表示あり | 非表示 |
| デザインテンプレート | ベーシック | プレミアム含む全て |
| API連携 | なし | Tracker.gg等 |
| カスタム背景 | なし | アップロード可能 |

### 投げ銭
- 開発者への応援機能（任意）

## 7. 画面構成（概要）

### 主要画面
1. **トップページ** - サービス紹介、カード作成への導線
2. **カード作成ページ** - ステップ形式でカード作成
3. **プレビュー・ダウンロードページ** - 作成したカードの確認・保存・シェア
4. **プロフィールページ** - シェアURL先の詳細表示ページ

### 画面フロー
```
トップ → ゲーム選択 → カード作成 → プレビュー → ダウンロード/シェア
                                      ↓
                              シェアURL → プロフィールページ
```

## 9. リスクと対策

| リスク | 対策 |
|--------|------|
| ゲームAPI利用規約変更 | 手動入力をベースとし、API連携は補助機能として位置づけ |
| 不適切画像のアップロード | 画像サイズ・形式制限、将来的にモデレーション導入 |
| 競合サービスの台頭 | シェアURL+詳細ページの独自価値で差別化 |
| サーバー負荷 | 画像生成の最適化、CDN活用 |

## 10. 用語定義

| 用語 | 説明 |
|------|------|
| プロフィールカード | ゲーマーの自己紹介情報をまとめたカード形式の画像 |
| シェアURL | カードごとに発行される固有のURL |
| プロフィールページ | シェアURL先で表示される詳細情報ページ |
| OGP | Open Graph Protocol。SNSシェア時のプレビュー表示に使用 |
