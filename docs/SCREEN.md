# 画面設計

## 1. 画面一覧

| 画面名             | パス          | 認証     | 説明                               |
| ------------------ | ------------- | -------- | ---------------------------------- |
| トップページ       | `/`           | 不要     | サービス紹介、カード作成への導線   |
| ログインページ     | `/login`      | 不要     | Discord / Google ログイン          |
| カード作成ページ   | `/create`     | **必要** | ゲーム選択〜カード情報入力         |
| プレビューページ   | `/preview`    | **必要** | 作成したカードの確認・保存・シェア |
| マイページ         | `/mypage`     | **必要** | 自分のカード一覧・管理             |
| プロフィールページ | `/cards/[id]` | 不要     | シェアURL先の詳細表示（公開）      |

## 2. 画面遷移図

```mermaid
flowchart TB
    subgraph Public ["公開ページ（認証不要）"]
        TOP[トップページ<br>/]
        LOGIN[ログインページ<br>/login]
        PROFILE[プロフィールページ<br>/cards/id]
    end

    subgraph Auth ["認証必要ページ"]
        CREATE[カード作成ページ<br>/create]
        PREVIEW[プレビューページ<br>/preview]
        MYPAGE[マイページ<br>/mypage]
    end

    subgraph External ["外部"]
        DISCORD[Discord OAuth]
        GOOGLE[Google OAuth]
        X[X / Twitter]
        DOWNLOAD[画像ダウンロード]
    end

    TOP -->|カードを作る| LOGIN
    TOP -->|ログイン済み| CREATE
    LOGIN -->|Discord| DISCORD
    LOGIN -->|Google| GOOGLE
    DISCORD -->|認証成功| CREATE
    GOOGLE -->|認証成功| CREATE
    CREATE -->|入力完了| PREVIEW
    PREVIEW -->|新しく作る| CREATE
    PREVIEW -->|マイページ| MYPAGE
    PREVIEW -->|Xでシェア| X
    PREVIEW -->|画像DL| DOWNLOAD
    PREVIEW -->|URLをコピー| PROFILE
    MYPAGE -->|カード選択| PROFILE
    MYPAGE -->|新規作成| CREATE
    X -->|リンククリック| PROFILE
    PROFILE -->|カードを作る| LOGIN
```

### カード作成ページ（`/create`）

#### 目的

- プロフィールカードの情報を入力
- リアルタイムでプレビュー確認

#### 要素一覧

| 要素             | 種類           | 説明                                     |
| ---------------- | -------------- | ---------------------------------------- |
| ゲーム選択       | セレクト       | 対応ゲームから選択（初期はVALORANTのみ） |
| プロフィール画像 | アップローダー | 画像アップロードまたはプリセット選択     |
| ゲーム内ネーム   | テキスト入力   | 最大20文字                               |
| ランク           | セレクト       | ゲームごとのランク一覧から選択           |
| メインキャラ     | セレクト       | エージェント/キャラ選択（複数可）        |
| プレイスタイル   | セレクト       | カジュアル/ランク/大会志向など           |
| ひとこと         | テキストエリア | 自己紹介、最大100文字                    |
| X ID             | テキスト入力   | @から始まるID                            |
| Discord ID       | テキスト入力   | username#0000形式                        |
| 背景選択         | ラジオボタン   | プリセット背景から選択                   |
| テーマ           | トグル         | ライト/ダーク                            |
| カードプレビュー | コンポーネント | リアルタイムプレビュー                   |

| カード操作メニュー | メニュー   | 削除、URLコピー                |

## 4. レスポンシブ対応

### ブレークポイント

| サイズ | 幅       | 対象デバイス       |
| ------ | -------- | ------------------ |
| sm     | 640px〜  | 大型スマートフォン |
| md     | 768px〜  | タブレット         |
| lg     | 1024px〜 | デスクトップ       |

### デバイス別レイアウト

#### カード作成ページ

- **モバイル**: プレビュー上部 + フォーム下部（縦積み）
- **デスクトップ**: フォーム左 + プレビュー右（横並び）

#### プロフィールページ

- **モバイル**: カード上部 + 詳細下部（縦積み）
- **デスクトップ**: カード左 + 詳細右（横並び）
